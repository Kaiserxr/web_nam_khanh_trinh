# Khanh Portfolio Website

## Description

This is my personal portfolio website.

## How it works

- Each folder in `src/app/` is a page (`/about`, `/cv`, `/moments`, `/portfolio`, `/experience`, `/contact`).
- The text comes from `src/data/` (`site.ts` for my info, plus `cv.json`, `experience.ts`, `projects.json`).
- Images and the resume PDF are in `public/`.

Run it locally with `npm install` and then `npm run dev`.

## Frameworks and Libraries

- Next.js 14
- Tailwind CSS
- [shadcn-ui](https://ui.shadcn.com)
- [magic-ui](https://magicui.design)
- [radix-ui / react-icons](https://www.radix-ui.com/icons)
- [framer-motion](https://www.framer.com/motion)
